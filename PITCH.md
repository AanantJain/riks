# RIKS — govern the remaining days

**Revision is Key to Success.** A family product for high-stakes exams.

Coaching already sells content. Families still guess tonight. RIKS is the governor: the named set before sleep, an in-app paper, and a plan that only moves after real work. Progress starts at **0%** until someone actually sits.

Live: [https://riks-yj2a.onrender.com](https://riks-yj2a.onrender.com)

## The problem

Coaching and YouTube are infinite. Time is not. Parents add sheets. Students pick at random. Progress looks busy. The exam date does not move.

Indian families already buy coaching. What they still do not have is a governor for the remaining days: what to sit tonight, why it matters for the mark sheet, and what the parent is allowed to help with.

## What RIKS is

One engine. Two exams. One loop a night.

It holds the clock, the marking scheme, and a personal skill model. It outputs a **minimum set before sleep** and an **in-app paper**. The plan rewrites from that paper. Empty bars on day one are the point: nothing is faked.

This is not another question bank.

| | Coaching / YouTube | RIKS |
|---|---|---|
| Who picks tonight | Student or parent, at random | Clock × marks × personal skill |
| What “done” means | Hours watched, sheets bought | Named set + submitted paper |
| Progress bar | Often seeded, looks busy | Starts at 0%. Moves after a paper |
| Parent role | Scold the % or add work | Help the named leak only |
| Product surface | Content library | Governor for remaining days |

## The loop

1. **See today** — Days left, this week’s subjects, the named set before sleep. No infinite feed.
2. **Sit the paper** — In-app daily exam. Topic-level notes. Not a content dump, not a scolding screen.
3. **Coach the leak** — Parent sees named chapters and “You can / Please do not.” Help the leak. Do not pile extra sheets. Do not scold a single %.

Tomorrow’s list and the progress bar change only after that paper.

## Two desks, same engine

**Wedge:** ship with one family and two high-stakes tracks, not a generic homework app. Same loop, different mark sheet.

**Aanant — contest.** Codeforces-style rating target. Tonight’s named problems, in-app drills. Live rounds stay on the actual judge; RIKS grades the home paper.

**Nikita — INI-CET / AIIMS PG.** 8-week subject block, hospital-duty hours, daily MCQs, weekly mock. Coach sees topic leaks, not a percentage to scold.

## Five minutes with an investor

1. Chooser: read the thesis, pick a desk.
2. Desk: remaining days. If no papers yet, progress is 0%.
3. Today → sit the paper → result names topics, not character.
4. Coach: “You can / Please do not.”
5. Other desk: same loop, different exam.

## Traction (honest)

No invented TAM, ARR, or waitlist. Traction today is a live family deploy, two exam types on one codebase, and a nightly loop short enough to show.

The landing is public. Desks sit behind a family password so progress stays off the public internet.
